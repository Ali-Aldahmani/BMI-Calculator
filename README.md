# 🏋️‍♂️ Modern BMI Calculator

A sleek, interactive, and modern Body Mass Index (BMI) calculator built entirely with Python. 

Unlike traditional terminal-based scripts, this application features a fully designed Graphical User Interface (GUI) that makes calculating your BMI intuitive and visually appealing.

## ✨ Key Features
* **Modern UI:** Built using `customtkinter` for a clean, dark/light mode adaptable interface.
* **Dual Unit System:** Effortlessly switch between Metric (Kilograms & Meters) and Imperial (Pounds & Inches) measurements with a single click.
* **Interactive Controls:** Features smooth sliders for height and dynamic +/- buttons for weight.
* **Real-time Updates:** Your BMI is calculated instantly as you interact with the controls—no "Calculate" button needed.
* **Cross-Platform:** Available as a standalone application for both **Windows** and **macOS**.

---

## 🚀 How to Use

You don't need Python installed to run this! Just download the version for your operating system:

### 🪟 For Windows Users
1. Go to the [Latest Release](https://github.com/Ali-Aldahmani/BMI-Calculator/releases/latest) page.
2. Download the `bmi-windowsOS.zip` file.
3. Extract the downloaded file.
4. Double-click the `bmi.exe` file and start calculating!

### 🍏 For macOS Users
1. Go to the [Latest Release](https://github.com/Ali-Aldahmani/BMI-Calculator/releases/latest) page.
2. Download the `bmi-macOS.zip` file.
3. Extract the downloaded file.
4. **Important:** Since this is an indie developer app, macOS might block it if you double-click it directly for the first time. Simply **Right-Click** the application, select **Open**, and confirm.
